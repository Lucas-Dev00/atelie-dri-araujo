# Ateliê Dri Araújo

Site desenvolvido para um ateliê de personalizados, permitindo que clientes visualizem produtos, catálogos e entrem em contato de forma rápida.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

- Página inicial
- Catálogo de produtos
- Monte sua festa
- Links para contato
- Layout responsivo
